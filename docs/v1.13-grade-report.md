# 1.13 — 학년 마무리 리포트

## 이번 단계

1.12.2(main, 649962b)에서 이어서 개발했다. 2월 마지막 날 야간 활동을 마치면 해당 학년의 성장과 기록을 마감한다. 활동 결과와 대기 대화를 본 뒤 학년 리포트가 열린다. 리포트를 확인하면 다음 학년의 일상을 진행하며, 기록 → 학년 일지에서 다시 볼 수 있다.

- 성장: 기존 `overallRating`과 `getNationalPercentile` 사용. 장비 효과 포함, 진급 전 동학년 기준 추정치를 비교한다.
- 팀: 시작/종료 역할, 감독·코치 평가, 공식전 개인 출전과 미출전을 구분한다. 출전 형태 없는 이전 기록은 별도로 표시한다.
- 대회: 기존 대진표를 요약한다. 1월 시즌 교체 직전 전년도 결과를 보존하여 3월 리포트에서 사라지지 않는다. 학교 성적이므로 선수 미출전 경기도 포함하고 청백전·연습경기는 제외한다.
- 인연: 해당 기간에 처음 3단계 이상에 도달한 인물. 회차별 이름을 사용한다.
- 업적: 시작 시점 이후 새로 획득한 기존 업적만 표시한다.
- 다음 훈련: 기존 컨디션·경기 폼·포지션 기반 조언을 재사용한다. 새로운 보너스나 임의의 감독 목표를 부여하지 않는다.

## 저장과 이전 버전

`gradeStartSnapshot`, `gradeReports`, `pendingGradeReportId`를 선수 저장에 추가한다. 별도 DB나 기록 엔진 없이 기존 데이터를 요약한 스냅샷이다. 진급 데이터와 보고서를 한 번에 저장하고, 확인 저장이 성공해야 팝업을 닫는다. 미확인 상태에서는 슬롯 진행을 막는다. 재접속하면 미확인 리포트가 유지되고, 확인한 리포트는 자동 재등장하지 않는다.

이전 버전은 최초 로드 시점부터 성장 비교를 시작하고 기간을 표시한다. 이미 사라진 전년도 대진표나 입학 당시 수치를 만들어 채우지 않는다. 2학년 진급과 3학년 졸업 시점도 각 학년으로 마감한다.
