# 2.0.7 고교 유니폼 레터링

## 참고와 적용

- [스포츠서울 덕수고 야구부 사진(2021)](https://www.sportsseoul.com/news/read/1031999): 붉은 영문 학교명, 각진 서체, 가슴선을 따라 올라가는 배치와 배색 테두리를 참고했습니다.
- [조선일보 부산고·경남고 사진(2021, 과거 선수 사진 포함)](https://www.chosun.com/sports/baseball/2021/02/28/SQEVISHKXNAK7OVUL3ZVZ2TMVM/): 굵은 한글 학교명, 밝은 외곽선, 영문 모자 표식을 참고했습니다.
- [연합뉴스 덕수고 청룡기 우승 사진(2025)](https://www.yna.co.kr/view/AKR20250712033500007): 팀 전체에서 학교명이 일관되게 보이는 구성을 확인했습니다.

사진은 시기별 참고 자료입니다. 게임용 유니폼이며 최신 공식 키트의 정확한 복제품으로 표시하지 않습니다. 사진 파일은 게임에 넣지 않았습니다.

영문 학교명은 Bevan의 굵은 슬래브 서체, 한글·한자는 기존 번들 Noto Sans KR의 굵은 서체를 사용합니다. 글자를 늘리지 않고 각각의 위치와 각도를 조정해 완만한 아치를 만듭니다. 학교 색의 얇은 테두리와 밝은 외곽선으로 원단 위에서 구분됩니다. 모자 영문도 같은 서체 계열을 사용합니다.

기존 중앙 26px 여밈선 여백과 긴 머리 외형의 오른쪽 가슴 배치는 유지합니다. 덕수고의 글씨는 사진을 참고해 붉은색·남색 테두리로 바꿨습니다. 기존 학교의 배색과 이름은 유지하며 실제 공식 로고를 복사하지 않았습니다.

Bevan 원본과 라이선스: [Google Fonts 저장소](https://github.com/google/fonts/tree/main/ofl/bevan). `scripts/fonts/Bevan-Regular.ttf`와 `Bevan-OFL.txt`를 함께 배포합니다. 재생성 지문에 폰트를 포함합니다.

## 결과물과 검증

91개 학교와 기본 키트 × 외형 8종, 736개 512×768 투명 이미지. 원화 32장은 유지합니다. 생성 이미지는 `public/assets/school-kits/`에 있고, Git 소스에서 `npm run kits`로 동일하게 재생성할 수 있습니다. 별도 결과물 ZIP도 제공합니다.

기존 자동 검사에는 모든 학교·외형의 실제 글자 렌더링에서 여밈선 여백을 확인하는 검사와 완성 이미지 크기·투명도 검사가 포함됩니다. 1학년 완주 검사도 유지합니다. 자동 검사와 빌드, 여러 학교·남녀 외형의 시각 검증을 확인하며 전체 수동 플레이 완료를 의미하지 않습니다.
