# 2.0.8 유니폼 글씨 보정

2.0.7에서 추정한 글자 간격과 개별 회전이 넓은 영문 글씨를 흐트러뜨리고 소매 경계를 넘게 했습니다. 이번에는 Sharp/Pango에서 실제 단어 폭을 측정해 단어 전체를 같은 기준선에 정렬합니다. 외형 8종의 앞 가슴판 좌우 경계를 따로 지정해 소매까지 학교명이 넓어지지 않도록 제한합니다.

영문 가슴 글씨는 넓은 슬래브 서체 대신 높고 굵은 Anton 블록 서체를 사용합니다. 원본과 OFL 라이선스를 번들에 포함합니다. [Google Fonts 원본](https://github.com/google/fonts/blob/main/ofl/anton/Anton-Regular.ttf). 모자 글씨는 기존 Bevan을 유지합니다.

학교명이 더 크게 보이도록 글자 높이를 확보하고 필요할 때만 단어 전체 폭을 최대 20% 압축합니다. 글자마다 폭·각도를 바꾸지 않습니다. 중앙 단추와 파이핑을 피하는 여백은 26px에서 20px로 조정했습니다. 긴 머리 외형은 오른쪽 가슴판의 두 줄로 표시해 기존의 작은 한 줄보다 크게 보입니다.

원화의 흰 원단·색상 마커와 알파를 사용해 글씨를 원단에만 합성합니다. 검은 머리·피부·투명 배경에는 글씨를 합성하지 않으며 최종 합성의 알파는 원화와 같게 유지합니다. 가슴판 경계와 원단 마스크를 함께 사용해 소매·옷 바깥으로 넘어가지 않도록 합니다.

이미지 재생성 중 Windows의 일시적인 파일 잠금으로 저장이 실패하는 경우에는 파일을 지우지 않고 이름 변경을 제한된 횟수로 재시도합니다. 진행 기록과 최종 이미지는 원자적으로 저장합니다.

91개 학교와 기본 키트 × 외형 8종, 736개 완성 이미지를 재생성합니다. 원화·폰트 라이선스는 유지합니다. 자동 검사는 모든 학교·외형의 실제 렌더링에서 중앙 여백을 확인하고, 원단 가장자리·머리·피부·투명 배경 마스크의 회귀 검사를 추가합니다. 1학년 완주 검사도 유지합니다. 시각 검증은 대표 학교와 외형의 원화 비교이며 전체 수동 플레이 검증을 의미하지 않습니다.

검증 결과: 자동 검사 93개, 린트·타입 검사·빌드 통과. 남녀 외형 8종 × 유니폼 4종의 32개 가슴 영역을 한 장으로 비교해 기준선·옷 경계·소매·긴 머리 배치를 확인했습니다. 대표 학교 6개 조합의 전체 원화 이미지도 결과물로 제공합니다.
