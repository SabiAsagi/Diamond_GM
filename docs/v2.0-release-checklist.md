# 2.0 최종 플레이 확인

2.0 개발과 자동 검증을 마쳤습니다. 최신 사용자 지시에 따라 실제 플레이 최종 확인은 나중에 진행합니다.

## 자동으로 확인한 범위

- 74개 검사, 실패/TODO 0; 빌드·린트 통과.
- 8개 1학년 완주: 각 364일·1,092슬롯, 실제 스토어 선택/경기/컷신/대진/월간 평가/저장 복원으로 다음 학년 도달.
- 3개년 연결: 2026-03-02 → 2029-03-01, 윤년 포함 1,095일·3,285슬롯. 월간 평가 36개·학년 리포트 3개·졸업 재접속 유지.
- 저장 실패 재시도, 동시 구매·장착·외형·시간 진행 보호, 부상 미리보기 난수 제외, 역할/공식 출전 집계, 전국체전 대표 선발·대진 진행, 겨울훈련 기간, 인연 상한.
- 한 해의 흐름/설정의 실제 컴포넌트 정적 렌더링.

스토어 검사는 메모리 저장으로 IndexedDB 경계를 대체합니다. 브라우저 실제 클릭·저장 장치 오류·모달 배치·화면 잘림·게임 재미를 검증한 것으로 보지 않습니다. 생성/면담 저장 실패 처리는 코드 검토와 타입체크 범위이며 실제 클릭 확인이 필요합니다.

## 나중에 플레이하면서 확인할 것

1. **시작과 재접속**: 새 선수 생성 → 감독 면담 → 홈 진입. 몇 활동 진행 후 시작 화면으로 돌아와 ‘이어서 하기’가 같은 날짜·슬롯·선수로 열리는지 확인합니다.
2. **화면과 저장**: PC와 휴대폰에서 활동 카드·결과·대화·대진표·학년 리포트가 잘리지 않는지, 중복 클릭으로 시간이 두 번 흐르지 않는지 봅니다.
3. **봄과 주전 경쟁**: 청백전·연습경기·이마트배·주말리그를 진행합니다. 경기 전 명단의 역할이 결과의 출전 형태와 맞고, 경기 후 평가와 코치 조언이 다음 행동에 보이는지 확인합니다.
4. **월간 계획**: 목표를 선언하고 표시된 활동을 수행합니다. 월말 평가/보상이 한 번만 생기며 다시 접속해도 기록이 같은지 확인합니다. 목표를 선택하지 않은 달도 진행할 수 있습니다.
5. **여름과 가을**: 황금사자기·청룡기·봉황대기, 방학 오전 자유 활동, 시·도 대표 선발전에 따른 전국체전 참가 여부를 확인합니다. 대표 선발전 탈락은 정상이며 일상을 계속 진행할 수 있습니다.
6. **겨울과 진급**: 12/24~2/5 겨울 전용 활동, 1월 전년도 대회 성적 보존, 2월 마지막 날 뒤 학년 리포트 → 확인 → 2학년 진행, 기록 → 학년 일지 다시 보기를 확인합니다.
7. **문제 기록**: 설정 → JSON 내려받기로 현재 저장본을 보관하고 버전·선수 포지션·학교·게임 날짜·시간대·직전 행동·화면 캡처를 함께 전달합니다. JSON 내보내기는 원본을 수정하지 않습니다. 가져오기 기능은 포함하지 않습니다.

## 현재 개발 범위

1학년의 생활·대회·경쟁·인연·월간 계획·학년 회고가 2.0의 범위입니다. 2·3학년의 일정/진급/졸업 기반도 유지하지만 상급 학년 전용 이야기 확충, 스카우트·드래프트·대학/프로 진출, 구단 모드 연동은 이후 개발입니다. 경기 결과 계산은 작동하며 배속 재생·승부처 수동 개입·음향은 준비 중입니다.
