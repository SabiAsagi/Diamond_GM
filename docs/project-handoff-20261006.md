## 계승할 사용자 요구
1. 모바일 웹을 우선한다. 훈련이 잘리지 않도록 하고 주요 항목을 한눈에 확인하는 UI를 유지한다.
2. 오전 학교생활 → 오후 야구 → 야간 휴식·취미·외출의 하루 3슬롯. 큰 활동 카테고리를 고른 뒤 시간대·포지션에 맞는 세부 활동을 선택한다.
3. 인연은 13명 개별 점수로 관리한다. Player.relationships가 저장 원본이며 활동·컷신은 relationshipTargets를 사용한다. 구 저장 마이그레이션과 첫날 면담 그룹 보정은 유지한다.
4. 이벤트는 인물 초상화와 주고받는 대화, 이벤트별 선택지·보상을 제공한다. 선택지가 없는 이벤트도 허용한다.
5. 인연 인물의 화풍을 일관되게 유지하고 전 인물 초상화를 제공한다. 학생 캐스트는 최신 AGENTS.md의 회차별 무작위·성별 무관 로맨스 규칙을 따른다.
6. 전국 퍼센타일은 동학년 기준 추정치로 표시한다. 라이벌은 매월 플레이어와 독립적으로 성장하며 리포트를 저장한다.
7. 야구장 관람은 홈경기 일정·취소·시간대를 확인한다. 가상 일정은 팀별 144경기·홈 72경기를 유지하고 월요일 예외를 다룬다.
8. 학교별 유니폼은 사진 자료를 참고한다. 현재 20개 사진 참고 배색과 나머지 게임용 배색을 구분하며 모든 학교를 최신 공식 유니폼으로 고증했다고 주장하지 않는다.
9. 버전·한글 변경 기록·한글 커밋/PR, GitHub 업로드와 변경 ZIP 제공 규칙을 유지한다. 실제 전체 플레이 최종 확인은 사용자가 수행한다.
