# 1.16 한 해의 흐름과 다시 시작하는 경로

- 홈에 5개 시기(봄·초여름·여름·가을·겨울)와 학년 마무리까지 남은 날짜를 표시합니다. 진행률은 학교 연도 기준이며 1월에 초기화되지 않고 윤년을 계산합니다. 지나온 시기는 대회 우승이나 개인 출전을 뜻하지 않습니다.
- 시작 화면에서 저장된 육성 선수를 선택합니다. 입학 면담 전 선수는 면담으로, 완료한 선수는 저장된 날짜로, 졸업 선수는 기록으로 이어집니다. 구단 모드 샘플 선수는 제외합니다.
- 설정에서 현재 선수 전체 JSON을 내려받아 문제 확인에 사용할 수 있습니다. 내보내기는 원본을 수정하지 않으며 가져오기 기능은 포함하지 않습니다.
- 부상 판정은 실제 수행에서만 난수를 굴립니다. 활동 미리보기는 성장·피로 보정만 계산합니다.
- 생성과 입학 면담의 저장 중 재클릭을 막고, 실패하면 입력/답변을 유지한 채 다시 시도합니다. 마지막 면담 답변은 저장 실패 시 중복으로 더하지 않습니다.
- 동작에 연결되지 않았던 경기 배속·수동 개입·음향 토글은 준비 중 안내로 교체했습니다. 기존 경기 결과 계산은 유지합니다.
- 상점/장착/외출 저장 오류를 표시하고 저장 중 버튼을 잠급니다. 낮은 컨디션의 회복 추천은 체력·멘탈까지 합친 실제 회복 효과를 따릅니다.
- 샘플 데이터 초기화를 IndexedDB 트랜잭션으로 묶어 중복 마운트 시 중복 삽입을 방지합니다.

검증: 8개 1학년 전체 슬롯(각 364일·1,092슬롯), 3개년 연결(1,095일·3,285슬롯), 졸업 재접속, 저장 실패·동시 저장·윤년·미리보기 난수·내보내기·이어서 하기 검사. 74개 통과, TODO 0. 실제 브라우저/IndexedDB/UI 플레이 최종 확인은 사용자가 이후 수행합니다.
