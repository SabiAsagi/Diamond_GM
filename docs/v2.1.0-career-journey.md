# 2.1.0 선수의 야구 인생

## 플레이 흐름

- 새 선수는 보호자를 알고 시작합니다. 기존 감독 면담을 마치면 감독이 등록되고, 학교에 들어가 담임 첫 만남을 진행합니다.
- 첫 주부터 짝꿍, 기술 코치, 동기, 주장, 체육 선생님, 예전 친구, 지역 라이벌을 순서대로 만납니다. 후배는 2학년부터 등장합니다. 인연 점수의 저장 원본은 기존 `Player.relationships`이며 만남 여부는 `careerJourney.met`입니다.
- 소개가 끝나기 전에는 해당 인물의 목록·개별 활동·인연 효과를 차단합니다. 대화 완료와 등록은 한 번의 저장으로 처리하고 재접속해도 대기 컷씬을 유지합니다. 기존 저장의 인물·이름·점수는 보존합니다.
- 1학년 첫 목표, 2학년 후배 지도·주전 경쟁·라이벌 재대결, 3학년 책임·마지막 여름·진로 상담을 선택형 컷씬으로 진행합니다. 학년 리포트가 대기 중이면 새 이야기를 미룹니다.

## 경기와 성장

- 선발·구원·대타 역할에서 경기 시작 전에 승부처 접근을 선택합니다. 투수는 정면 승부/코너 공략/구종 조합, 타자는 컨택/장타/선구안 접근을 선택합니다. 미선택은 기존 감독 기본 접근입니다. 벤치·엔트리 제외 선수는 수동 개입을 제공하지 않습니다.
- 접근은 능력과 피로를 기준으로 팀 승리 확률과 개인 안타·홈런·실점 계산을 바꿉니다. 요약 경기의 한 번의 접근이며 전체 이닝 재생은 구현 범위가 아닙니다. 실제 선택과 성적은 기존 경기 기록에 함께 보존합니다.
- 만난 동기·기술 코치의 인연 55부터 각각 출전 경기 승리 확률 +2.5%p를 제공합니다. 기존 감독/동기 훈련 효과와 선배 조언은 유지합니다. 인연 상세에도 새 효과를 표시합니다.
- 학교는 불펜/타석/수비·주루 중 한 가지 훈련 성향을 갖습니다. 해당 능력의 훈련 성장이 5% 증가합니다. 이는 실제 학교 평가가 아닌 게임 내 설정입니다.
- 정보 → 육성 일지에서 실제 증가한 훈련 능력의 누적 기록, 학년 이야기, 인연 수, 스카우트 관심과 진로를 확인합니다. 경기 기록에서도 활용한 훈련 성장을 표시합니다.

## 진로와 졸업

- 3학년 9월부터 제안을 열고, 1~2월에도 같은 졸업 시즌으로 처리합니다. 공식 출전만 세며 벤치와 연습/청백전은 제외합니다.
- 대학: 학업 45·종합 능력 30·공식 출전 4경기. 프로: 종합 능력 60·인지도 35·공식 출전 10경기. 해외 육성팀: 종합 능력 72·인지도 55·공식 출전 12경기. 지역 클럽은 항상 가능합니다.
- 얻은 제안은 유지되고 졸업 전에는 선택을 변경할 수 있습니다. 미선택은 지역 클럽 결말입니다. 졸업 결말의 진로·종합 능력·공식 출전 수를 한 번 저장하며 이후 바꾸지 않습니다.
- 제안은 게임용 분기입니다. 대학/프로/해외에 진출한 뒤의 경기와 구단 모드 연동은 이번에 포함하지 않습니다.

## 검증 범위

새 커리어 첫 만남·대화 완료·저장 실패·재접속, 소개 전 활동 차단, 기존 저장 보존, 출전 역할별 접근과 실제 기록, 진로 요건·선택·졸업 멱등성, 학교 성향·인연 효과·성장 기록을 검사합니다. 기존 1학년 완주 8종 중 한 종과 윤년 포함 3개년 연결을 새 만남 방식으로 진행합니다.

실제 브라우저에서는 새 선수 생성 → 감독 면담 → 담임 첫 만남 → 인연 목록 → 육성 일지의 화면/저장을 확인합니다. 전체 3년을 사람이 수동 플레이한 검증과 자동 스토어 완주는 구분합니다.

최종 결과: 자동 검사 100개 통과, 정적 검사와 배포 빌드 성공. PC와 390px 모바일에서 육성 일지를 확인했고 모바일 가로 넘침은 없었습니다. 새 인연·학년 이야기·진로 제안 알림과 소개 전 인연 알림 차단도 검증했습니다.
