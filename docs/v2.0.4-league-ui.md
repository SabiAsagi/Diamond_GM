## 게임 일정과 이전 저장본

전반기 첫 토요일은 3월 7일 이후, 후반기는 5월 23일 이후로 잡고 주 단위로 편성합니다. 전국대회와 겹치면 주말리그를 다음 토요일로 미룹니다. 게임의 전국대회 시작일은 이마트배 4월 15일, 황금사자기 5월 2일, 청룡기 7월 1일, 대통령배 7월 22일, 봉황대기 8월 15일입니다. 이는 육성 진행을 위한 게임 날짜입니다.

전국대회는 모든 학교에 열린 공개 추첨으로 4팀 조별 토너먼트 예선을 치르고 조 우승팀이 본선 16강에 진출하는 기존 구조입니다. 현실의 예선 성적별 진출권, 전체 참가 팀 규모, 올스타전·국제대회는 이번 변경에서 구현하지 않았습니다. 전국체전과 도 예선은 기존 구조를 유지합니다.

이전 생성기의 ID를 가진 남은 주말리그만 교체합니다. 완료 경기·과거 일정·사용자 정의 일정은 보존하며, 완료 경기가 이미 6경기를 넘은 반기는 추가 경기를 생성하지 않습니다. 기존 전국대회 날짜를 소급 변경하지 않으며 아직 시작 전인 대통령배만 누락 시 추가합니다.

## UI와 새 소식

네이비 클럽하우스와 아이보리 선수 일지를 혼합하고 주황색을 주요 행동에 사용합니다. 홈, 시작·선수 생성·면담 화면과 하단 메뉴의 색감을 정리했습니다. 짧은 모바일 화면에서는 훈련 목록 내부를 스크롤하고 완료 버튼을 유지합니다.

능력 단계·새 특성·아이템·인연 단계, 경기·학년 기록, 월간 계획·월간 결과·업적·트로피를 메뉴와 세부 탭의 빨간 점으로 안내합니다. 표시된 소식 확인 버튼은 현재 표시된 최대 5개만 읽음 처리합니다. 다른 탭의 소식은 남고 읽음 ID는 선수 저장본에 유지됩니다. 저장 실패 시 읽음 상태도 변경하지 않습니다.
