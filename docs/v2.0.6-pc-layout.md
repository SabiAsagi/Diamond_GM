# 2.0.6 PC 화면 보정

선수 이미지의 내부 크기에 남아 있던 40×60px 강제 규칙을 PC 선수 카드 안에서 해제했습니다. 기본 PC 카드는 원화의 2:3 비율인 64×96px, 낮은 PC 화면은 48×72px를 사용하며 이미지가 비율을 유지해 표시됩니다. 모바일 카드의 기존 크기는 유지합니다.

사용자의 최종 요청에 따라 PC 홈은 스크롤 없이 하루 활동을 선택하고 완료하는 화면으로 구성했습니다. 왼쪽의 연간 진행과 월간 목표 요약은 홈에서 빼고 각각 기록·목표 메뉴에서 확인합니다. 활동 카드의 설명과 보상 표시를 유지하며, 낮은 화면에서는 하루 진행 표시를 한 줄로 배치합니다.

1280×720와 1280×900에서 홈 전체, 활동 4개와 완료 버튼을 확인했습니다. 1280×720의 휴식·훈련 카드 모두 내부 높이와 내용 높이가 같고 페이지 높이가 720px여서 잘림이나 스크롤이 없습니다. 기록 메뉴는 내용 높이 1689px의 페이지 스크롤이며 작은 카드 내부 스크롤을 사용하지 않습니다. 375px 모바일은 기존 본문 스크롤과 하단 메뉴를 유지합니다.

높이 650px 이하 또는 폭 1100px 이하의 작은 PC 창에서는 가독성을 위해 홈도 페이지 전체 스크롤로 전환합니다. 긴 기록·인연 목록은 한 화면에 강제로 압축하지 않습니다.

자동 검사 92개(1학년 완주 포함), 린트·타입 검사·빌드 통과. UI 변경의 브라우저 검증이며 전체 수동 플레이 완료를 의미하지 않습니다.
