# 2.0.5 선수 일지 UI

## 구성

PC에서는 왼쪽에 클럽 메뉴, 위에 선수 등록 카드, 본문에 선수 요약과 하루 활동 보드를 둡니다. 모바일은 하단 메뉴를 유지하며 본문 전체를 스크롤합니다. 활동 설명과 완료 버튼은 목록을 따라 자연스럽게 이어지고 메뉴 전환 시 본문을 처음부터 보여줍니다.

시작 화면은 선수 일지 표지와 기존 선수 원화를 사용합니다. 클럽하우스의 네이비, 일지의 아이보리, 선택과 진행의 주황색을 유지하면서 더 루키와 다른 화면 구조를 구성했습니다.

## 스킬 적용

설치된 UI UX Pro Max의 스포츠 대시보드 검색, 가독성·터치 대상 지침을 참고했습니다. 검색 결과의 큰 정보 블록은 게임에 맞게 적용했지만 마케팅용 Hero Centric 구조와 붉은 추천 팔레트는 게임 본문에 그대로 적용하지 않았습니다. 한글 가독성, 기존 캐릭터 원화, 하루 세 번 선택하는 흐름에 맞춰 조정했습니다.

모바일 활동 제목 16px, 설명 13px, 충분한 버튼 높이, 선과 체크를 함께 사용하는 선택 표시를 적용했습니다. 키보드 초점, 본문 바로가기, 장식 아이콘 숨김, 분류 버튼의 선택 상태를 제공합니다. 작은 화면에서는 본문 내부의 고정 높이 활동 스크롤을 없앴습니다.

기존 Figma의 클럽하우스·선수 일지 디자인은 방향 참고 자료이며, 이번 2.0.5 구현의 정확한 화면은 브라우저 검증 이미지와 소스입니다. Figma에 2.0.5 화면을 동기화했다고 표시하지 않습니다.

## 검증 범위

- `npm test`: 92개 통과. 기존 1학년 완주 통합 검사 포함.
- `npm run lint`, `npm run build`: 린트·타입 검사·프로덕션 빌드.
- 실제 Chrome: 새 선수 생성과 입학 면담, 입학식 완료, 오후 활동 완료 후 야간 전환, 정보의 읽음 표시, 기록·목표·설정 메뉴.
- 화면 폭 1280px, 375px, 320px와 768×375 가로 화면: 가로 넘침과 본문·메뉴 영역 확인.
- PC 및 모바일 검증 이미지를 결과물로 제공합니다.

자동 완주와 짧은 브라우저 조작을 검증했습니다. 전체 3년의 수동 플레이를 완료한 것은 아니며 최종 실제 플레이는 사용자 확인 대상입니다. 배포 전 PR에서 검토하며 기존 공개 사이트 반영과 PR 생성은 구분합니다.
