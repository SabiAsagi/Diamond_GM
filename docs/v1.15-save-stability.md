# 1.15 저장 안정화

구매·장착·외형·외출·대진 공개는 슬롯 진행과 같은 `isLoading` 잠금을 사용합니다. 한 저장이 진행 중일 때 다른 변경은 실행하지 않으며, 성공한 후 다시 선택할 수 있습니다. 실패 시 메모리/슬롯을 확정하지 않고 잠금을 풀어 재시도를 허용합니다. 대시보드 로드 오류와 슬롯 저장 오류도 사용자에게 표시합니다.

졸업 시 `careerEndedAt`을 저장합니다. 재접속은 이 값이나 기존 3학년 보고서로 종료를 복원합니다. 졸업 날에는 다음 학년의 랜덤 이벤트나 라이벌 월간 보고서를 만들지 않습니다. 졸업 상태의 경기/훈련/구매/장착/외출/목표 선언은 진행하지 않습니다.

검증: 실제 스토어에서 저장을 일시 중단해 동시 호출을 재현했고, 중복 구매·차감·장착·슬롯 진행·외형 덮어쓰기 방지를 검사했습니다. 초기화/장착 실패 재시도와 졸업 저장본의 재접속도 검사합니다. 실제 IndexedDB와 브라우저 클릭 검증은 별도입니다.
