## 1학년 완주 자동 검증 (1.10 도입, 1.11 전국체전 추가)

실행: `npm run test:freshman`. 전체 회귀: `npm test`. PR 검증 워크플로와 main 배포 워크플로 모두 전체 테스트를 실행한다. 워크플로 추가만으로 GitHub의 필수 검사/브랜치 보호 설정을 변경하지는 않는다.

`freshman_year.cjs`는 실제 TypeScript 소스를 임시 CommonJS로 컴파일하고 게임 스토어를 실행한다. 실제 `selectActivity`·`executeForcedSlot`·`resolveCutscene`·`revealTournament`·`dismissRivalReport`를 사용한다. 날짜를 직접 수정하거나 경기 승패를 강제하지 않는다. 활동은 시간대·등교일·포지션 조건을 만족하는 후보에서 선택하며 피로가 쌓이면 휴식한다.

타자/S학교(seed 19), 투수/D학교(seed 110), 투타겸업/B학교(seed 2026)를 각각 실행한다. 고정 시드는 실패 재현을 위한 것이며 승패를 고정값으로 대체하지 않는다. 실행 종료 후 난수 함수는 복원한다. 각 시나리오는 별도의 초기 선수로 시작하며 게임은 2026년 3월 2일 오전부터 2027년 3월 1일 오전까지 364일·1,092슬롯을 진행한다.

검사 항목:

- 날짜·요일·슬롯 연속성과 2학년 진급, 조기 커리어 종료 없음
- 전국대회 5종(1.11 전국체전 포함), 주말리그, 청백전·연습경기 진행 및 저장된 결과
- 경기일을 넘긴 미진행 경기와 중복 경기 없음
- 여름·겨울 방학 오전 자유 활동
- 컷신, 조 추첨, 월간 보고서 처리와 정체 방지
- 47슬롯마다 및 월 경계에서 저장본 재접속: 시계·대회·개인 기록·경쟁 상태·대기 이벤트 유지
- 능력치 유효 범위, 동기 진급, 연간 경기 기록 보존
- 실패 시 시드·진행 슬롯 수·최근 8개 행동 출력

1.10 초기 실행에서 세 시나리오 모두 35회 재접속, 12회 월간 보고서, 4회 조 추첨을 거쳤다. 1.11부터는 전국체전을 포함해 조 추첨이 5회이며, 세 시나리오 모두 전국체전 경기를 1회 이상 치른다. 학교 경기 수는 37/36/37회였고 컷신은 124/139/153회였다. 경기 진행에는 벤치·엔트리 제외도 포함한다. 이는 학교 일정 통과를 뜻하며 선수 개인의 실제 출전을 강제하지 않는다.

## 1.11 전국체전

- 시·도별 대표 1개교(데이터상 16개 시·도)가 10월 17일부터 3일 간격으로 16강 → 8강 → 4강 → 결승을 치른다. 플레이어 학교는 소속 시·도 대표로 자동 출전하고, 다른 시·도는 해당 지역 최상위 티어 학교 중 1개교를 무작위로 뽑는다.
- 기존 조 추첨·라운드 진행·트로피 구조를 그대로 사용한다(`entry: 'provincial'`).
- 이전 버전 저장본은 불러올 때 전국체전이 아직 개막 전이면 1라운드 대진을 보완하고, 개막 이후면 소급 추가하지 않는다.
- 1.10의 TODO는 일반 검사로 전환했다. 현재 **46개 통과, TODO 0개**.

## 아직 미충족인 조건

1.12 겨울훈련, 1.13 학년 마무리 리포트, 실제 UI 플레이 검증이 남아 있다. 이 조건이 모두 충족되기 전에는 v2.0 완성으로 표시하지 않는다.

저장은 구조화 복사한 메모리 객체를 사용하므로 실제 IndexedDB 영속성·브라우저 클릭·모달 배치·렌더링·사용자가 느끼는 지루함은 검증하지 않는다. 입학 면담을 마친 대시보드 상태에서 시작하므로 생성/입학 UI도 범위 밖이다. 이것은 **스토어 통합 완주 테스트**이고 브라우저 E2E 검사를 대체하지 않는다.
