## 환경 및 검증 범위

Windows 작업 환경이 자식 프로세스 생성을 제한하여 테스트는 동일 파일을 Node의 --test-isolation=none 옵션으로 실행했습니다. Vite는 --configLoader native 옵션으로 빌드했습니다. 저장소의 일반 npm 스크립트와 Linux CI 설정은 유지합니다.

로컬 검증에는 설치돼 있던 TypeScript 6.0.3 및 Sharp 0.35.4를 사용했습니다. 잠금 파일은 요청된 TypeScript 6.0.2 및 Sharp 0.35.5를 유지하며 GitHub CI는 npm ci로 고정 버전을 설치합니다.

실제 브라우저에서 IndexedDB 저장·복원과 전체 학년을 수동으로 플레이하는 최종 확인은 기존 계획대로 사용자 확인 대상입니다. 원화 시각 검수와 자동 테스트가 이를 대신한다고 주장하지 않습니다.
