# 랜덤 인연 인물 초상화

새 회차에서 인연 인물의 이름과 초상화를 무작위로 정할 때 사용하는 이미지 모음이야.

- `senior`, `peer`, `rival`: 역할마다 남자 8명·여자 2명, 야구복 초상화 10장
- `childhood`, `neighbor`, `deskmate`: 역할마다 여자 5명·남자 5명, 교복·사복 초상화 각 10장
- 전체 이미지: 90장
- 파일 형식과 크기: WebP, 1024×1536
- 친구 계열에서 번호가 같은 `school`과 `casual` 파일은 동일 인물이야.

이름과 파일 경로 목록은 `src/data/randomRelationshipProfiles.ts`에서 관리해.
